# Aura Detailing Studio - Премиальный детейлинг автомобилей

Высококонверсионный лендинг, разработанный для студии премиального ухода за автомобилями в Таллине. Проект сфокусирован на формировании визуального доверия, стильной демонстрации результатов "до/после" и удобном процессе записи через модальное окно.

## Особенности проекта

* **Конверсионный UI/UX:** Современный, строгий темный дизайн, идеально подходящий для продвижения локальных услуг премиум-класса.
* **Блоки До/После:** Интерактивная демонстрация качества выполненных работ (керамическое покрытие, полировка).
* **Удобная запись (Booking Flow):** Кастомное всплывающее окно (modal) для быстрой отправки заявок без перехода на другие страницы.
* **Визуальное доверие:** Акцент на качественные изображения автомобилей и чистую сетку для передачи профессионализма студии.
* **Полная адаптивность:** Безупречное отображение на десктопах, планшетах и мобильных телефонах.

## Технологии

* **HTML5:** Семантическая разметка.
* **CSS3:** Flexbox, CSS Grid, кастомные анимации и медиазапросы.
* **JavaScript (Vanilla):** Управление модальными окнами, интерактивными элементами и плавным скроллом. Никаких сторонних библиотек.

## Структура файлов

* `index.html` — Главный HTML-документ.
* `style.css` — Все стили проекта.
* `script.js` — Скрипты для работы интерактива и модального окна.
* `img/` — Директория с изображениями (автомобили, фоны, иконки).

## Как запустить

Проект состоит исключительно из фронтенд-части и не требует сборщиков (NPM, Webpack) или локального сервера.

1. Скачайте или клонируйте этот репозиторий на свой компьютер.
2. Откройте файл `index.html` в любом современном веб-браузере (Chrome, Safari, Firefox).
3. Готово!
