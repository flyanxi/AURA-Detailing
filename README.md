# Aura Detailing Studio

A high-converting, premium landing page developed for a high-end car care and detailing studio based in Tallinn. The project is focused on building visual trust, showcasing before/after results, and providing a seamless modal booking flow to turn visitors into leads.

## Project Features

* **Conversion-Optimized UI:** A sleek, modern design tailored for local luxury services and automotive perfection.
* **Before/After Showcases:** Interactive sections designed to demonstrate the high quality of paint correction and ceramic coating work.
* **Seamless Booking Flow:** A custom, fully responsive modal window for quick and easy consultation requests.
* **Visual Trust:** Emphasis on high-quality imagery, dark aesthetics, and a strict layout to convey professionalism.
* **Fully Responsive:** A flawless browsing experience across desktops, tablets, and mobile devices using modern CSS.

## Technologies

* **HTML5:** Semantic and accessible markup.
* **CSS3:** Flexbox, CSS Grid, custom animations, and responsive media queries.
* **JavaScript (Vanilla):** Logic for the booking modal, interactive showcases, and smooth scrolling without bloated frameworks.

## File Structure

* `index.html` — Main HTML document.
* `style.css` — Project stylesheets.
* `script.js` — Main interactivity logic (modals, scrolling).
* `img/` — Directory for images (backgrounds, car showcases, icons).

## How to Run

This project consists solely of frontend technologies and does not require a local server or build tools.

1. Download or clone this repository to your local machine.
2. Open the `index.html` file in any modern web browser (Chrome, Safari, Firefox).
3. Done!
